## ✨ 最新更新（由 OpenClaw AI 助理协作完成）

### 新增：小学 5 年级四则混合运算打印题库
- 页面：[`math/math-4digit-mixed-print.html`](https://karryzhang.github.io/codingdad/math/math-4digit-mixed-print.html)
- 定位：小学五年级练习，数字范围为 **1~4 位数**（不强制全 4 位）
- 支持题型：四则混合运算（+ / - / × / ÷），可选“标准混合”与“含括号混合”
- 打印规则：**每页 20 题**，适合线下纸质练习
- 教学友好：附带 **答案页打印**，题号与题目页一一对应，便于家长/老师批改

> 本次功能设计、实现与排版优化由 **OpenClaw AI 助理** 协作完成。
