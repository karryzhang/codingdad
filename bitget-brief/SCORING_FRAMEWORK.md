# Bitget Wallet 战略简报 - 内容评分框架

## 总体原则

评分目标：**筛选对 Bitget Wallet 战略决策最有价值的信息**

总分满分: **100 分**

---

## 三维评分体系

### 1️⃣ **媒体权威度评分** (权重: 30%)

衡量信息源本身的可信度和专业程度

#### A 级媒体 (95-100 分)
- **英文**: CoinDesk, The Block, Decrypt, Cointelegraph (官方编辑团队)
- **中文**: 律动 BlockBeats, 深潮 TechFlow, 链捕手 (第一手采访)
- **专业**: GitHub Ethereum 官方, Dune Analytics 官方数据
- **特点**: 原创深度内容, 一手资源, 编辑团队严谨

#### B 级媒体 (80-92 分)
- Foresight News, The Defiant, Bankless
- 星球日报, 链上侦察
- Polymarket 市场信号, Santiment 数据分析
- **特点**: 有专业判断, 数据驱动, 但可能存在解读差异

#### C 级媒体 (60-75 分)
- 一般财经/科技媒体转发
- Twitter/X 高信誉账号评论
- 行业论坛讨论
- **特点**: 可能有二手信息, 需要交叉验证

#### D 级媒体 (低于 60 分)
- 自媒体臆测、小博主
- 无按名的转发账号
- 低质论坛讨论
- **不纳入**: 纯社交媒体段子、无来源的传言

---

### 2️⃣ **事件影响力评分** (权重: 35%)

衡量信息本身在行业的重要程度和影响范围

#### 政策/监管类 (85-100)
- SEC/FinCEN 重大裁决或指导意见
- 各国金融监管新政策或执法行动
- CLARITY Act 等大型法案进展
- **评判**: 影响整个行业或生态, 具有强制性

#### 技术里程碑类 (75-95)
- EIP 正式入主网（如 EIP-7702）
- Layer 2 重大升级（Arbitrum、Optimism 发布）
- 钱包基础设施突破（AA、Social Login 普及）
- 跨链桥接安全增强
- **评判**: 改变技术方向, 影响用户体验

#### 竞品重大动作 (70-90)
- MetaMask、Rabby、Coinbase 钱包关键功能发布
- 融资、收购、战略合作宣布
- 安全漏洞或被黑事件
- **评判**: 改变竞争格局, 用户迁移风险

#### 市场量能/流向类 (65-85)
- USDT 大额流向变化 (>$1B)
- 稳定币监管松绑/收紧
- 链上交易量异常变化
- 交易所流出/流入大幅变动
- **评判**: 反映用户行为变化, 交易机会

#### 融资/生态事件 (60-75)
- RWA 项目大额融资或上线
- AI Agent 融资/发布
- DeFi 协议重大更新
- **评判**: 市场热点, 但可能是短期现象

#### Meme/社区热点 (50-70)
- Meme 币交易量突破
- 预测市场赔率异常变动
- 链上社区情绪指标
- **评判**: 用户需求信号, 但易变且投机性强

---

### 3️⃣ **战略相关度评分** (权重: 35%)

衡量信息对 Bitget Wallet 业务的直接影响

#### PayFi 域 (支付金融)
**最直接相关** (95-100):
- USDT/稳定币流向、监管变化 → 直接影响 on/off-ramp 渠道
- 跨链桥接成本、安全事件 → 影响支付体验与成本
- B2B2C 支付监管新规 → 开辟新市场机会
- 交易对深度、流动性变化 → 决定交易体验

**间接相关** (70-90):
- 宏观政策、汇率变化
- 竞品支付相关发布

#### 钱包竞争域 (去中心化竞争)
**最直接相关** (95-100):
- MetaMask/Rabby AA、Social Login 发布 → 直接产品竞争
- EIP-7702 主网部署 → 技术债务, 必须适配
- 钱包安全漏洞 → 用户信心与产品需求

**间接相关** (70-90):
- Layer 2 性能升级 → 影响平台选择
- 新 EIP 提案进展 → 前瞻性规划

#### 交易能力域 (Meme/Perps/RWA/美股)
**最直接相关** (95-100):
- Meme 交易量创新高 → Meme 功能优化紧迫性
- Perps 新品发布、OI 深度 → Perpetuals 模块重要性
- RWA 融资与采用 → 产品方向验证
- 美股交易聚合需求 → 功能规划

**间接相关** (70-90):
- 通用市场情绪、大宗商品价格

## 综合评分计算公式

```
最终评分 = (媒体权威度 × 0.30) + (事件影响力 × 0.35) + (战略相关度 × 0.35)
```

### 评分区间解释

| 分数区间 | 含义 | 行动 |
|---------|------|------|
| **90-100** | 🔴 **必入** - 高度关键信息 | 立即纳入简报 + 标记 CRITICAL |
| **75-89** | 🟠 **应入** - 重要参考信息 | 默认纳入简报 |
| **60-74** | 🟡 **可入** - 有价值但非关键 | 配额允许时纳入 |
| **<60** | 🔵 **不入** - 参考价值有限 | 排除 |

## 简报配额分配

**每个域 3 条信息，优先原则：**

1. **90-100 分** 的信息优先级最高（CRITICAL 绝对入选）
2. **75-89 分** 的信息按相关度排序
3. **60-74 分** 的信息作为补充

**单个来源限制**：同一媒体最多不超过 2 条（避免重复覆盖）

## 真实数据采集规则

### 信息源优先级

**第一优先**（最优先采集）:
```
支付/流动性: CoinDesk PayFi 专栏 + Dune 链上数据
竞品动向: CoinDesk + The Block 采访 + GitHub Official
交易市场: Dune Analytics + Santiment 数据 + Foresight 分析
```

**第二优先**：
```
中文媒体: 链捕手独家采访 + 律动 BlockBeats 原创分析
监管政策: 各国 FinCen/SEC 官方声明 + Decrypt 解读
技术升级: Ethereum GitHub + LayerZero 官方更新
```

### 采集验证步骤

1. **搜索** - 使用 Brave API 搜索关键词
2. **获取** - 通过 web_fetch 获取原文链接和内容
3. **验证** - 确认信息源权威度 + 发布时间 + 完整性
4. **评分** - 按三维框架打分
5. **排序** - 按综合分数排序，筛选 Top 9

## 简报质量约束

### 必须包含字段

每条信息**必须**包含：
```json
{
  "title": "新闻标题",
  "source": "权威媒体名称",
  "time": "发布时间（相对或绝对）",
  "url": "原文直接链接（验证可访问）",
  "impact": "对 Bitget Wallet 的具体影响（1-2句）",
  "authority_score": 85,      // 媒体权威度
  "impact_score": 90,          // 事件影响力
  "relevance_score": 92,       // 战略相关度
  "final_score": 89            // 最终综合分数
}
```

### 排除标准（自动丢弃）

- ❌ 链接无法访问或已过期
- ❌ 信息来源低于 C 级 + 无交叉验证
- ❌ 发布时间超过 48 小时（陈旧信息）
- ❌ 重复信息（同一事件的转发）
- ❌ 无具体数据的泛泛而谈
- ❌ 综合评分 < 60 分

## 案例：评分真实示范

### Example 1: MetaMask AA 发布

```
标题: "MetaMask 发布 Account Abstraction 集成，支持 EIP-7702"
来源: CoinDesk (A 级)
时间: 今天 10:00 UTC

媒体权威度: 98 (CoinDesk 一手报道)
事件影响力: 95 (直接改变钱包竞争格局，EIP-7702 首次主流应用)
战略相关度: 98 (钱包直接产品竞争，技术债务)

最终评分 = (98 × 0.30) + (95 × 0.35) + (98 × 0.35)
         = 29.4 + 33.25 + 34.3
         = 96.95 → **97 分** ✅ CRITICAL ENTRY
```

### Example 2: 小币种上线 DEX

```
标题: "XYZ Token 在 SushiSwap 上线"
来源: Cointelegraph 社区报道 (C 级)
时间: 2 小时前

媒体权威度: 65 (转发性质，无深度分析)
事件影响力: 40 (微观级别，无行业影响)
战略相关度: 35 (与 Bitget Wallet 无直接关系)

最终评分 = (65 × 0.30) + (40 × 0.35) + (35 × 0.35)
         = 19.5 + 14 + 12.25
         = 45.75 → **46 分** ❌ REJECTED
```

## 实施建议

1. **周期性审视**: 每周抽样检查 3-5 条入选信息，验证评分准确性
2. **权重调整**: 根据实际业务变化调整权重（PayFi 热度高时可适当提升相关度权重）
3. **黑名单管理**: 记录低质来源，逐步排除
4. **反馈闭环**: 用户对简报的反馈直接影响下周的排序调整
